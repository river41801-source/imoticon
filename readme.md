# 실시간 이모티콘 보내기 웹앱

초보자 수업에서 학생들이 실시간으로 반응을 보내고, 강사가 반 전체 반응을 확인할 수 있는 단일 HTML 웹앱입니다.

## 실행 방법

1. `index.html` 파일을 더블클릭합니다.
2. 브라우저에서 첫 화면이 열리면 `강사 모드` 또는 `학생 모드`를 선택합니다.
3. 인터넷에 연결되어 있어야 Firebase Realtime Database와 실시간으로 연결됩니다.

## 화면 구성

- 첫 화면: `강사 모드`, `학생 모드` 선택
- 학생 화면: `👍 좋아요`, `❤️ 공감해요`, `👏 응원해요` 반응 전송
- 강사 화면: 실시간 반응 애니메이션, 종류별 누적 횟수, 전체 반응 횟수 확인

## 강사 모드 비밀번호

- 비밀번호: `1004`
- 이 비밀번호는 실습용 화면 진입 제한입니다.
- 실제 데이터 보안을 보장하지 않습니다.

## Firebase 설정

- Firebase Realtime Database를 사용합니다.
- 데이터 저장 경로는 `practice/reactions`입니다.
- Firebase Authentication 로그인이나 회원가입은 사용하지 않습니다.
- Firebase 콘솔에서 Realtime Database 보안 규칙을 테스트 모드로 설정해야 수업 실습 중 전송이 됩니다.

## 사용 전 확인

- 인터넷 연결 상태를 확인해 주세요.
- Firebase Realtime Database가 만들어져 있는지 확인해 주세요.
- 테스트 모드 규칙이 꺼져 있으면 반응 전송이 실패할 수 있습니다.
